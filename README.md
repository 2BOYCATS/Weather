# Weather ⛅

โปรเจกต์แสดงสภาพอากาศนี้ใช้ฝึกเรียกข้อมูลจาก `OpenWeather API` ด้วย fetch แบบ async/await ระบบดึงตำแหน่งปัจจุบันจาก `Geolocation API` ของเบราว์เซอร์ ส่งไปขอข้อมูลสภาพอากาศ แล้วเก็บค่าที่ได้ไว้ในออบเจกต์ก่อนนำมาแสดงผล ได้แก่ ไอคอน อุณหภูมิ คำอธิบายสภาพอากาศ และชื่อเมือง ชื่อประเทศ

🔗 [Live Demo](https://2boycats.github.io/Weather/)

## ✨ Features
- แสดงสภาพอากาศตามตำแหน่งปัจจุบันของเครื่อง
- ไอคอนเปลี่ยนไปตามสภาพอากาศจริง
- แสดงอุณหภูมิ คำอธิบายสภาพอากาศ ชื่อเมือง และชื่อประเทศ

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- [OpenWeather API](https://openweathermap.org/api)
- Geolocation API (ของเบราว์เซอร์)

## 🚀 วิธีรันโปรเจกต์
1. เปิดโฟลเดอร์โปรเจกต์ด้วย VS Code
2. สมัครและขอ API key ฟรีได้ที่ [OpenWeather](https://openweathermap.org/api)
3. นำ API key ไปใส่ในไฟล์ `app.js`:
   ```javascript
   const apiKey = "YOUR_API_KEY";
   ```
4. ใช้ Live Server เปิดไฟล์ `index.html`
5. กด **Allow** เมื่อเบราว์เซอร์ขออนุญาตเข้าถึงตำแหน่ง

## 🔄 การทำงานของระบบ
1. ขอตำแหน่งปัจจุบันจาก `Geolocation API` (ละติจูด/ลองจิจูด)
2. ส่งตำแหน่งไปขอข้อมูลสภาพอากาศจาก `OpenWeather API` ด้วย `fetch`
3. เก็บข้อมูลที่ต้องใช้ไว้ในออบเจกต์
4. นำข้อมูลในออบเจกต์ไปแสดงผลบนหน้าเว็บ

## 📝 หมายเหตุ
- เบราว์เซอร์ต้องรองรับ `Geolocation` และผู้ใช้ต้องอนุญาตให้เข้าถึงตำแหน่ง ไม่เช่นนั้นจะดึงข้อมูลไม่ได้
- ต้องเรียก API ผ่าน `https://` เท่านั้น เพราะหน้าเว็บบน GitHub Pages โหลดผ่าน HTTPS ถ้าใช้ `http://` เบราว์เซอร์จะบล็อกด้วย Mixed Content error
- หากไม่กด **Allow** เมื่อเบราว์เซอร์ขออนุญาตเข้าถึงตำแหน่งจะไม่สามารถแสดงสภาพอากาศได้

## 📚 สิ่งที่ได้เรียนรู้
- การใช้ `fetch` ควบคู่กับ `async/await` เพื่อดึงข้อมูลจาก API
- การอ่านและเลือกใช้ข้อมูลจาก JSON ที่ API ส่งกลับมา แล้วเก็บไว้ในออบเจกต์ก่อนนำไปแสดงผล

## 🔮 แผนพัฒนาต่อ
- เพิ่มปุ่มสลับหน่วยอุณหภูมิ เช่น เซลเซียส (°C) เป็นฟาเรนไฮต์ (°F)
